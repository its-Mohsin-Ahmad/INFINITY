Hades II

Supergiant Games|Supergiant Games|2025|Indie · Action · Story Rich
9.1182,783 reviews
PCSwitch

Hades II marks another independent entry from Supergiant Games, and roguelike and roguelite is the thread that ties it together. Post-launch support has been steady, with content drops that add rather than dilute. Hades II is a independent experience from Supergiant Games, built around roguelike and roguelite. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Tight, focused runtime built around one strong idea
  • Hand-crafted art direction with a signature visual identity
  • Full controller and Steam Deck verification
  • Escalating set pieces that always hand control back to the player
  • Ability progression that reshapes how encounters are approached
  • Boss encounters built around readable tells and punish windows
  • Procedurally arranged runs built from hand-authored templates
  • Mutators for player-authored difficulty

Modes

single playercampaign

How it plays

  1. 01Objective — Chain offence and defence mid-combat, reading enemy tells before committing to a heavy attack.
  2. 02Learn which attacks are unblockable; those are the ones you must dodge, not parry.
  3. 03Practise cancelling heavy attacks into a dodge until the timing feels automatic.
  4. 04Use the environment — ledges, hazards and choke points — to control multi-enemy fights.
  5. 05Upgrade one weapon fully before buying a second; scaling beats variety early on.
  6. 06Unlock the first tier of the skill tree and commit to one damage path instead of spreading points.
  7. 07Keep a ranged or throwable option for enemies that punish pure melee aggression.
  8. 08Platform note — 2 storefronts tracked on INFINITY, each with its own install size and requirements.
