Space Engineers

Keen Software House|Keen Software House|2019|Sandbox · Simulation · Multiplayer
8.249,052 reviews
PCPS5PS4Xbox X|SXbox One

Keen Software House built Space Engineers as a sandbox sandbox first and a showcase second, with space sim and sandbox craft as the spine. Controls are readable within minutes and deep enough that advanced players keep finding new tech. Space Engineers is a sandbox experience from Keen Software House, built around space sim and sandbox craft. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. The pacing alternates between tense build-up and explosive payoff, which keeps long sessions from flattening out. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Cross-platform worlds with host controls
  • Moderation and reporting tooling for shared spaces
  • Community showcase feeds and featured builds
  • Interlocking systems where every resource has a supply chain
  • Dynamic events and disasters that force replanning
  • Simulation depth with difficulty modifiers and sandbox toggles
  • Newtonian flight with docking and trade routes
  • Logic, wiring and automation systems

How it plays

  1. 01Objective — Balance throughput against cost, and expand only as fast as logistics can sustain.
  2. 02Set up the first resource chain end to end before adding a second.
  3. 03Play one long session with a single goal in mind; simulation games reward clear objectives.
  4. 04Save often, and label saves before large redesigns.
  5. 05Use blueprints for anything you will build more than twice.
  6. 06Once the basics are automatic, increase demand and see which system fails first.
  7. 07Keep spare capacity in power, storage and transport so growth is never gated by infrastructure.
