Elex II

Piranha Bytes|THQ Nordic|2022|RPG · Open World · Action
7.143,406 reviews
PCPS5PS4Xbox X|SXbox One

Elex II is a role-playing experience from Piranha Bytes, built around action rpg and sci-fi. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. Elex II is what happens when Piranha Bytes commits fully to role-playing and action rpg and sci-fi. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Companion arcs with approval states and unique questlines
  • Deep build crafting across skill trees, gear stats and passives
  • Hand-authored side quests with consequences beyond the reward
  • Seamless traversal with no loading transitions between regions
  • Fast travel that unlocks only once a zone has been explored
  • Discovery-led design — landmarks are the map marker
  • Real-time combat with stat-driven damage maths
  • Hardware, ship and station design language

Modes

single playercampaigncross platform

How it plays

  1. 01Objective — Set your own route through a living map, treating exploration itself as progression.
  2. 02Upgrade inventory or carrying capacity early; it compounds for the entire game.
  3. 03Use map markers to note places you cannot access yet.
  4. 04Return to earlier regions once abilities open up — gated content is often the best content.
  5. 05Follow the main path for the first few hours — it usually unlocks key traversal or ability upgrades.
  6. 06Save before entering unknown territory; open worlds punish overconfidence late at night.
  7. 07Clear nearby points of interest before moving to a new region so fast travel is always covered.
