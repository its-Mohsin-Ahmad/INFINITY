Days Gone

Bend Studio|Sony Interactive Entertainment|2019|Action · Open World · Horror · Survival
7.950,215 reviews
PCPS4

From Bend Studio, Days Gone is a action game where post-apocalyptic and monster hunt drives almost every decision. The pacing alternates between tense build-up and explosive payoff, which keeps long sessions from flattening out. Days Gone is what happens when Bend Studio commits fully to action and post-apocalyptic and monster hunt. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. Systems interlock cleanly, so mastery in one area visibly improves outcomes in another. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Boss encounters built around readable tells and punish windows
  • Weighty melee and firearm combat with animation-driven hit reactions
  • Escalating set pieces that always hand control back to the player
  • Fast travel that unlocks only once a zone has been explored
  • Seamless traversal with no loading transitions between regions
  • A living map of dynamic events, convoys and emergent encounters
  • Improvised gear and radiation systems
  • Monster AI with sensory perception and stalking behaviour

Modes

single playercampaign

How it plays

  1. 01Objective — Set your own route through a living map, treating exploration itself as progression.
  2. 02Upgrade inventory or carrying capacity early; it compounds for the entire game.
  3. 03Talk to every named NPC once. Many open side quests and reward chains.
  4. 04Return to earlier regions once abilities open up — gated content is often the best content.
  5. 05Mix quest types to avoid fatigue: a main mission, a side story, then free exploration.
  6. 06Use map markers to note places you cannot access yet.
  7. 07Clear nearby points of interest before moving to a new region so fast travel is always covered.
  8. 08Platform note — 2 storefronts tracked on INFINITY, each with its own install size and requirements.
