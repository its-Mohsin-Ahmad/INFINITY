Dragon Ball FighterZ

Arc System Works|Bandai Namco Entertainment|2018|Fighting · Multiplayer · Action
8.648,738 reviews
PCPS5PS4Xbox X|SXbox OneSwitch

Arc System Works returns with Dragon Ball FighterZ, a fighting title that leans hard into arena shooter. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. From Arc System Works, Dragon Ball FighterZ is a fighting game where arena shooter drives almost every decision. The pacing alternates between tense build-up and explosive payoff, which keeps long sessions from flattening out. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. The presentation is confident — strong art direction, an adaptive score and clean, uncluttered HUD work. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Rollback netcode with region-aware matchmaking
  • Frame data and training tools built into the client
  • Tutorial and combo challenges for every character archetype
  • Skill-based matchmaking with transparent rating tiers
  • Seasonal progression with challenges and rewards
  • Anti-cheat, reporting and spectator review tooling
  • Short match formats built for ranked play
  • Ranked seasons with visible rating changes and placement matches

How it plays

  1. 01Objective — Control spacing and frame advantage, then punish predictable behaviour with a full combo.
  2. 02Watch your own replays and count how often you press a button while minus.
  3. 03Use training mode's frame data display to check whether moves are safe on block.
  4. 04Complete the tutorial and the character-specific combo trials before ranked.
  5. 05Learn one character's normals, one anti-air and one reliable punish.
  6. 06Practise blocking low attacks on reaction, then add delayed tech.
  7. 07Play long sets rather than first-to-one; adaptation is the real skill.
