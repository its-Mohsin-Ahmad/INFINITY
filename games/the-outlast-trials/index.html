The Outlast Trials

Red Barrels|Red Barrels|2024|Horror · Co-op · Survival
8.055,089 reviews
PCPS5PS4Xbox X|SXbox One

First launched in 2024, The Outlast Trials remains a reference point for horror design built on survival horror and party. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. The Outlast Trials is a horror experience from Red Barrels, built around survival horror and party. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. The presentation is confident — strong art direction, an adaptive score and clean, uncluttered HUD work. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Finite resources that make every decision count
  • Sanity, light and stamina systems that raise tension
  • Persistent threats that learn and reposition
  • Friends Pass access so a squad only needs one copy
  • Drop-in and drop-out with join-in-progress checkpoints
  • Proximity voice with optional speech-to-text
  • Ammo scarcity and inventory management under pressure
  • Four-player chaos with rubber-banded stakes

How it plays

  1. 01Objective — Establish shelter and a resource loop before pushing into higher-risk regions.
  2. 02Track day-night and weather cycles; both change which threats are active.
  3. 03Do not fight every fight. Running is a valid response to a bad engagement.
  4. 04Prioritise food, water and shelter in the first hour; everything else is optional.
  5. 05Store duplicate resources — the inventory you lose on death is the one that hurts.
  6. 06Build a small base near resources but away from high-traffic enemy paths.
  7. 07Craft the basic tool set before exploring further than you can walk back.
