Armored Core VI: Fires of Rubicon

FromSoftware|Bandai Namco Entertainment|2023|Action · Simulation · Multiplayer
8.666,554 reviews
PCPS5PS4Xbox X|SXbox One

Armored Core VI: Fires of Rubicon is what happens when FromSoftware commits fully to action and sci-fi and management. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. Released in 2023, Armored Core VI: Fires of Rubicon is FromSoftware's take on modern action design with sci-fi and management at its centre. Systems interlock cleanly, so mastery in one area visibly improves outcomes in another. Progression is generous but earned, with new tools arriving exactly when the challenge curve demands them. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Boss encounters built around readable tells and punish windows
  • Photo mode with depth-of-field, focal length and filter controls
  • Escalating set pieces that always hand control back to the player
  • Long-tail progression measured in hundreds of hours
  • Simulation depth with difficulty modifiers and sandbox toggles
  • Blueprint, layout and automation tooling
  • Speculative technology with in-world justification
  • Staff, morale and logistics across departments
