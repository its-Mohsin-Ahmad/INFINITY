Metroid Dread

MercurySteam|Nintendo|2021|Action · Adventure
8.860,806 reviews
Switch

Metroid Dread takes the action blueprint and rebuilds it around platformer and metroidvania. Difficulty is a dial rather than a wall — assists can be layered without ever feeling like training wheels. MercurySteam returns with Metroid Dread, a action title that leans hard into platformer and metroidvania. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. Progression is generous but earned, with new tools arriving exactly when the challenge curve demands them. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Weighty melee and firearm combat with animation-driven hit reactions
  • Escalating set pieces that always hand control back to the player
  • Adaptive difficulty that scales aggression, not enemy health
  • Interconnected level design that rewards curiosity
  • Environment-driven storytelling with no cut-scene interruptions
  • Accessibility suite covering navigation, timing and colour
  • Collectibles and time trials per stage
  • Ability-gated world that loops back on itself

Modes

single playercampaign

How it plays

  1. 01Objective — Chain offence and defence mid-combat, reading enemy tells before committing to a heavy attack.
  2. 02Learn which attacks are unblockable; those are the ones you must dodge, not parry.
  3. 03Start on standard difficulty and use early encounters to learn the dodge window rather than trading hits.
  4. 04Unlock the first tier of the skill tree and commit to one damage path instead of spreading points.
  5. 05Upgrade one weapon fully before buying a second; scaling beats variety early on.
  6. 06Use the environment — ledges, hazards and choke points — to control multi-enemy fights.
  7. 07Set aside time for optional challenges: they usually unlock the strongest tools in the game.
  8. 08Platform note — 1 storefront tracked on INFINITY, each with its own install size and requirements.
