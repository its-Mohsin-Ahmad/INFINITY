Amnesia: The Bunker

Frictional Games|Frictional Games|2023|Horror · Survival
8.166,396 reviews
PCPS4Xbox X|SXbox One

Amnesia: The Bunker takes the horror blueprint and rebuilds it around stealth and psychological horror. Difficulty is a dial rather than a wall — assists can be layered without ever feeling like training wheels. First launched in 2023, Amnesia: The Bunker remains a reference point for horror design built on stealth and psychological horror. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. The pacing alternates between tense build-up and explosive payoff, which keeps long sessions from flattening out. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Finite resources that make every decision count
  • Optional one-life mode for the committed
  • Sanity, light and stamina systems that raise tension
  • Base building with structural and defensive layers
  • Deep inventory and weight management
  • Crafting trees spanning tools, shelter, medicine and vehicles
  • Ghost, assault and mixed approach scoring
  • No-combat stretches that rely on atmosphere

Modes

single playercross platform

How it plays

  1. 01Objective — Establish shelter and a resource loop before pushing into higher-risk regions.
  2. 02Do not fight every fight. Running is a valid response to a bad engagement.
  3. 03Play with one friend early; co-op scales difficulty but doubles carrying capacity.
  4. 04Build a small base near resources but away from high-traffic enemy paths.
  5. 05Track day-night and weather cycles; both change which threats are active.
  6. 06Prioritise food, water and shelter in the first hour; everything else is optional.
  7. 07Store duplicate resources — the inventory you lose on death is the one that hurts.
  8. 08Platform note — 4 storefronts tracked on INFINITY, each with its own install size and requirements.
