Rust

Facepunch Studios|Facepunch Studios|2018|Survival · Multiplayer · Action
8.4111,507 reviews
PCPS5PS4Xbox X|SXbox One

Rust pairs survival systems with crafting and extraction, and it is a stronger game for it. Progression is generous but earned, with new tools arriving exactly when the challenge curve demands them. Rust is what happens when Facepunch Studios commits fully to survival and crafting and extraction. Every mechanic feeds the fantasy: if it looks like it should work, the simulation generally allows it. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. Controls are readable within minutes and deep enough that advanced players keep finding new tech. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Base building with structural and defensive layers
  • Day-night and seasonal cycles that change what is available
  • Crafting trees spanning tools, shelter, medicine and vehicles
  • Dedicated server architecture with a 60Hz+ tick rate
  • Anti-cheat, reporting and spectator review tooling
  • Cross-platform parties and shared progression
  • Player-market pricing on every extracted item
  • Ranked seasons with visible rating changes and placement matches

Modes

single playermultiplayeronline pvprankedcross platform

How it plays

  1. 01Objective — Establish shelter and a resource loop before pushing into higher-risk regions.
  2. 02Store duplicate resources — the inventory you lose on death is the one that hurts.
  3. 03Prioritise food, water and shelter in the first hour; everything else is optional.
  4. 04Play with one friend early; co-op scales difficulty but doubles carrying capacity.
  5. 05Bring a dedicated combat loadout when gathering, and a gathering loadout when fighting.
  6. 06Do not fight every fight. Running is a valid response to a bad engagement.
  7. 07Build a small base near resources but away from high-traffic enemy paths.
  8. 08Platform note — 5 storefronts tracked on INFINITY, each with its own install size and requirements.
