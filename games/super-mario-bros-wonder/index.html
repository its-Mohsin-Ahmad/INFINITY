Super Mario Bros. Wonder

Nintendo EPD|Nintendo|2023|Family · Co-op
9.2100,881 reviews
Switch

Nintendo EPD returns with Super Mario Bros. Wonder, a family-friendly title that leans hard into platformer and party. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. From Nintendo EPD, Super Mario Bros. Wonder is a family-friendly game where platformer and party drives almost every decision. The pacing alternates between tense build-up and explosive payoff, which keeps long sessions from flattening out. Difficulty is a dial rather than a wall — assists can be layered without ever feeling like training wheels. The core loop rewards planning: scout the situation, commit resources, then adapt when the plan collapses. Online play is the main event, with dedicated servers and skill-based matchmaking. It is a premium release with no live-service grind bolted on.

Highlights

  • Simple onboarding that teaches without tutorials
  • Local split-screen and pass-and-play support
  • Assist modes that any player in the room can enable
  • Asymmetric roles that demand genuine coordination
  • Friends Pass access so a squad only needs one copy
  • Drop-in and drop-out with join-in-progress checkpoints
  • Collectibles and time trials per stage
  • Four-player chaos with rubber-banded stakes
