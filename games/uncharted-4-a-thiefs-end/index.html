Uncharted 4: A Thief's End

Naughty Dog|Sony Interactive Entertainment|2016|Action · Adventure · Story Rich
9.358,114 reviews
PCPS5PS4

First launched in 2016, Uncharted 4: A Thief's End remains a reference point for action design built on cover shooter. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. Naughty Dog returns with Uncharted 4: A Thief's End, a action title that leans hard into cover shooter. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. The pacing alternates between tense build-up and explosive payoff, which keeps long sessions from flattening out. Difficulty is a dial rather than a wall — assists can be layered without ever feeling like training wheels. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Boss encounters built around readable tells and punish windows
  • Adaptive difficulty that scales aggression, not enemy health
  • Escalating set pieces that always hand control back to the player
  • Accessibility suite covering navigation, timing and colour
  • Interconnected level design that rewards curiosity
  • Environment-driven storytelling with no cut-scene interruptions
  • Blind fire, snap cover and flank-happy AI
  • Full offline single-player support with no always-online requirement

Modes

single playercampaign

How it plays

  1. 01Objective — Chain offence and defence mid-combat, reading enemy tells before committing to a heavy attack.
  2. 02Unlock the first tier of the skill tree and commit to one damage path instead of spreading points.
  3. 03Learn which attacks are unblockable; those are the ones you must dodge, not parry.
  4. 04Practise cancelling heavy attacks into a dodge until the timing feels automatic.
  5. 05Start on standard difficulty and use early encounters to learn the dodge window rather than trading hits.
  6. 06Upgrade one weapon fully before buying a second; scaling beats variety early on.
  7. 07Keep a ranged or throwable option for enemies that punish pure melee aggression.
  8. 08Platform note — 3 storefronts tracked on INFINITY, each with its own install size and requirements.
