PlateUp!

It's Happening|Yogscast Games|2022|Co-op · Simulation
8.366,185 reviews
PCPS5PS4Xbox X|SXbox OneSwitch

PlateUp! marks another co-operative entry from It's Happening, and roguelike and management is the thread that ties it together. Post-launch support has been steady, with content drops that add rather than dilute. It's Happening returns with PlateUp!, a co-operative title that leans hard into roguelike and management. Session length is flexible, so a run can be fifteen minutes or a full evening without either feeling wrong. Systems interlock cleanly, so mastery in one area visibly improves outcomes in another. Accessibility is treated as a first-class feature, covering remapping, subtitles and timing tolerance. A full single-player campaign is included and can be finished without ever touching the online modes. It is a premium release with no live-service grind bolted on.

Highlights

  • Asymmetric roles that demand genuine coordination
  • Designed from the ground up for two to four players
  • Proximity voice with optional speech-to-text
  • Detailed statistics and analytics dashboards
  • Dynamic events and disasters that force replanning
  • Blueprint, layout and automation tooling
  • Procedurally arranged runs built from hand-authored templates
  • Financial modelling with real consequences

How it plays

  1. 01Objective — Balance throughput against cost, and expand only as fast as logistics can sustain.
  2. 02Once the basics are automatic, increase demand and see which system fails first.
  3. 03Keep spare capacity in power, storage and transport so growth is never gated by infrastructure.
  4. 04Play one long session with a single goal in mind; simulation games reward clear objectives.
  5. 05Start in sandbox or creative mode to learn the building and automation tools without pressure.
  6. 06Set up the first resource chain end to end before adding a second.
  7. 07Watch the analytics panels to find the bottleneck rather than expanding everything at once.
